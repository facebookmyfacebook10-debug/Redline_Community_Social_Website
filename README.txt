REDLINE COMMUNITY — FACEBOOK-INSPIRED BUSINESS SOCIAL WEBSITE
=============================================================

This ZIP contains a responsive social-style website concept for Redline Outdoor & Power, using the product images and catalogue from the uploaded Redline Outdoor & Power website ZIP.

OPEN ON WINDOWS
---------------
1. Extract this ZIP with right-click > Extract All.
2. Open the extracted folder.
3. Double-click index.html to preview in Chrome.

FEATURES IN THIS FRONT-END DEMO
-------------------------------
- Responsive social-media-inspired feed and navigation.
- Seeded business/product posts using supplied product photos.
- Create posts with text and an optional image.
- Like/unlike, comment, save and share post text.
- Search feed posts and search/filter the product catalogue.
- Community profile display name.
- Demo group join buttons.
- WhatsApp enquiry links using the supplied site-config.js number.
- Product cards populated from products.js and assets/images.

IMPORTANT LIMITATIONS
---------------------
This is a front-end demo, not a production multi-user social network. Demo posts, comments, likes, saved posts and profile name are stored in the current browser only using localStorage. They are not shared with other visitors and may be cleared by clearing browser data.

The login/profile popup is not account authentication. Messaging and notifications are explanatory demo interactions. Real account registration, secure login, multi-user posts, real-time messaging, admin dashboard, database storage and moderation require a backend (for example Supabase/PostgreSQL), server-side authorisation and security configuration. Do not publish this as a production social network until that backend is built and tested.

BUSINESS DETAILS
----------------
The supplied Redline site configuration is included in site-config.js, including the WhatsApp number and address from the uploaded Redline website. Confirm these details before publishing.

CUSTOMISING PRODUCTS
--------------------
Edit products.js to update the product catalogue. Image filenames are assets/images/photo-NNN.jpg. The current page shows sample product cards and sample business posts based on the provided product catalogue. Confirm product specifications, prices, stock and other claims with the business before adding them.

PUBLISHING
----------
You can host this static demo on GitHub Pages or another static host. A hosted static demo still does not become a real multi-user social network without a backend.
